# Autoelétrica — conceito de landing page

Prévia estática independente, sem dependências de build. `index.html` contém o conceito inicial; os dados da empresa e os serviços são demonstrativos e precisam de confirmação antes de publicação definitiva.

## Preservação

O projeto é versionado em Git local e no repositório público `andreydecorvital-sudo/ned-preview-autoeletrica`. O primeiro commit preserva o HTML original.

## Prévia

O GitHub Pages publica a branch `master` em `https://andreydecorvital-sudo.github.io/ned-preview-autoeletrica/`. A página e o repositório são públicos: não incluir segredos, dados pessoais ou conteúdo privado. A publicação desta landing não constitui implementação do fluxo reutilizável NED Preview.

Uma futura integração NED Preview deverá publicar somente artefatos explicitamente selecionados, com autorização, proteção adequada, controle de custo, identificação do commit, logs, atualização e rollback. Não usar a configuração do domínio de produção como atalho nem publicar diretórios da VPS.
