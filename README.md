# Autoelétrica — conceito de landing page

Prévia estática independente, sem dependências de build. `index.html` contém o conceito inicial; os dados da empresa e os serviços são demonstrativos e precisam de confirmação antes de publicação definitiva.

## Preservação

O projeto é versionado em Git local. O primeiro commit preserva o HTML original; este repositório ainda não tem backup remoto configurado.

## Prévia

Não há deploy HTTPS configurado neste repositório. Não usar a configuração do domínio de produção como atalho e não publicar diretórios da VPS. Uma futura integração NED Preview deverá publicar somente artefatos explicitamente selecionados, com autorização, proteção adequada, controle de custo, identificação do commit, logs, atualização e rollback. Não tratar esta descrição como implementação de NED Preview.
